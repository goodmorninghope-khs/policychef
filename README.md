# 정책셰프 김현성

뜻과 땀으로 때를 짓는 정책셰프 김현성의 프로필 사이트.
『소상공인을 버린 AI』를 축으로 책 이전(땀) · 책(뜻) · 책 이후(때)를 정리합니다.

- `kitchen.html` + `kitchen.js`: three.js로 만든 3D 정책셰프(김현성을 닮은 곱슬머리·금테 동그란 안경·남색 재킷·줄무늬 넥타이)와 정책 주방. 메뉴를 고르면 뜻·땀·때 항아리에서 재료가 날아들고 접시가 나옵니다
- 정적 HTML 몇 장 + `style.css` + `site.js`(모바일 메뉴·스크롤 등장) + `img/` 폴더
- 첫 화면은 큰 세 줄 헤드라인 → 강연·현장 → 주제 → 뜻땀때 이야기 → 점선면 → 약력 → 문의 순서
- 문의 폼은 서버 없이 메일 앱을 엽니다. 받을 주소는 `index.html`의 `#contact-form` `data-to` 한 곳에만 적습니다
- Vercel에서 저장소를 가져오면 별도 설정 없이 바로 발행됩니다.
