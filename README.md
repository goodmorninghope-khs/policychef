# 정책셰프 김현성

뜻과 땀으로 때를 짓는 정책셰프 김현성의 프로필 사이트.
『소상공인을 버린 AI』를 축으로 책 이전(땀) · 책(뜻) · 책 이후(때)를 정리합니다.

- 정적 HTML 몇 장 + `style.css` + `site.js`(모바일 메뉴·스크롤 등장) + `img/` 폴더
- 첫 화면은 큰 세 줄 헤드라인 → 강연·현장 → 주제 → 뜻땀때 이야기 → 점선면 → 약력 → 문의 순서
- 문의 폼은 서버 없이 메일 앱을 엽니다. 받을 주소는 `index.html`의 `#contact-form` `data-to` 한 곳에만 적습니다
- Vercel에서 저장소를 가져오면 별도 설정 없이 바로 발행됩니다.

뜻땀때 스튜디오 · Songs for Davids

## 연계 (밸류체인)

이 저장소는 [policy-media-desk](https://github.com/goodmorninghope-khs/policy-media-desk) 밸류체인의 **⑥ 기록** 고리다. 상태: 제안 (발행인 확인 후 실제로 이으면 '연계'로 바꾼다).

- 받음: 정책 미디어 창간 경과·선례 요약(사실 확인된 공식 기록만)
- 넘김: 정책셰프의 뜻·땀·때 아카이브 → 확장 매체의 선례 자료
- 넘길 때는 출처 지면(지면명·호수·날짜·링크)과 '닿는 공약'을 붙이고, 침은 의견으로 남긴다. 결정은 받는 고리의 책임자가 한다.
